# 🐙 Git e GitHub

Anotações e práticas sobre controlo de versões com Git e integração com o GitHub.

## 📌 Comandos Principais
* `git init` - Inicializa um repositório local.
* `git status` - Exibe o estado dos ficheiros (working tree / staging area).
* `git add .` - Adiciona as alterações para a staging area.
* `git commit -m "mensagem"` - Grava as alterações no histórico.
* `git push origin main` - Envia os commits locais para o repositório remoto.
* `git log --oneline` - Exibe o histórico de commits de forma resumida.

# Exercício: Account e BusinessAccount

## Objetivo

Praticar os conceitos de herança em Java, utilizando uma classe base Account e uma classe especializada BusinessAccount.

## Funcionalidades

- Criar uma conta comum.
- Criar uma conta empresarial.
- Realizar depósitos.
- Realizar saques.
- Realizar empréstimos dentro do limite permitido.

## Conceitos praticados

- Herança (`extends`).
- Reutilização de atributos e métodos.
- Construtores.
- Palavra-chave `super`.
- Encapsulamento.
- Especialização de classes.

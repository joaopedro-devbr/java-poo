# 🧩 Enumerações e Composição

Estudos sobre o uso de tipos enumerados (`enum`) e o conceito de composição de objetos em Java (relações "tem-um").

## 📌 Conteúdos do Módulo
* Tipos enumerados (Enums)
* Conversão de String para Enum
* Composição de Objetos (relações entre entidades)
* Exercícios práticos de contratos de trabalhadores e pedidos

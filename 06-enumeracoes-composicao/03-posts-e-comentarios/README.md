# Exercício: Posts e Comentários

## Objetivo

Desenvolver um sistema de publicações com comentários, utilizando os conceitos de Programação Orientada a Objetos em Java.

## Conceitos praticados

- **Composição:** relacionamento entre Post e Comment.
- **Listas:** armazenamento de vários comentários utilizando ArrayList.
- **Encapsulamento:** atributos privados com getters e setters.
- **Construtores:** inicialização dos objetos.
- **Sobrescrita:** utilização do método toString().
- **StringBuilder:** construção de textos para exibição.

## Funcionamento

O programa cria duas publicações, cada uma com data, título, conteúdo, quantidade de curtidas e comentários.

Ao final, exibe as informações completas de cada publicação, incluindo seus comentários.

# Exercício: Sistema de Pedidos

## Objetivo

Desenvolver um sistema de pedidos utilizando os conceitos de Programação Orientada a Objetos em Java, trabalhando com composição entre classes, enumerações e listas de objetos.

## Funcionalidades

- Cadastro de clientes.
- Cadastro de pedidos.
- Definição do status do pedido.
- Cadastro de produtos e quantidades.
- Associação de produtos aos itens do pedido.
- Cálculo do subtotal de cada item.
- Cálculo do valor total do pedido.
- Exibição do resumo completo do pedido.

## Conceitos praticados

- Classes e objetos.
- Construtores e sobrecarga.
- Encapsulamento.
- Enumerações (`enum`).
- Composição.
- Listas (`ArrayList`).
- Métodos e sobrescrita de `toString()`.
- Manipulação de datas com `Date` e `SimpleDateFormat`.
